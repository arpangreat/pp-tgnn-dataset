A Detection-Bias-Corrected Temporal Event-Stream Dataset for Dynamic
Plant–Pollinator Link Prediction

Abstract
We present a reprocessed, machine-learning-ready version of a public H.J. Andrews LTER plant–pollinator visitation
dataset (2011–2018, 2021; 180 plots, 18 meadows, 147 plant species, 800 pollinator taxa), purpose-built for dynamic link
prediction with Temporal Graph Neural Networks. Starting from two raw survey files (74,942 visitation rows; 23,642
flowering-phenology rows), we separate genuine interactions from structural non-detections. We then correct for imperfect
pollinator detection using a Royle-type Poisson N -mixture model, fitted through vectorized numerical marginal-likelihood
maximization. Next, we compute a phenology-based confidence weight for each interaction. Finally, we assemble the
data into a continuous-time weighted event stream and apply a leakage-safe chronological split. The resulting dataset
comprises 20,107 weighted interaction events and 1,389 empirically grounded negative (surveyed, non-detected) events.
We document every processing decision, including two pitfalls specific to these data: a silent date-format mismatch
between the source files and a real multi-year survey gap that can lead to incorrect results with naive calendar-based
splitting. These details are provided to ensure that the dataset can be reused reliably.
Keywords: Temporal graph learning, dynamic link prediction, plant–pollinator networks, N-mixture model, detection
bias, ecological network data

def log_marginal_over_lamgrid(y, lam_grid, p, n_trunc_extra=30):
y = np.asarray(y)
n_max = int(y.max()) + n_trunc_extra
n_range = np.arange(int(y.max()), n_max + 1)
# (Nc,)
# log P(y_k | N) summed over replicates k, independent of lambda
log_lik_k = binom.logpmf(y[:, None], n_range[None, :], p) # (K, Nc)
log_lik_sum = log_lik_k.sum(axis=0)
# (Nc,)
# log Poisson prior over N for every lambda in the grid at once
log_prior_N = poisson.logpmf(n_range[:, None], lam_grid[None, :])

# (Nc, L)

log_joint = log_lik_sum[:, None] + log_prior_N
# (Nc, L)
m = log_joint.max(axis=0, keepdims=True)
log_ml = (m + np.log(np.sum(np.exp(log_joint - m),
axis=0, keepdims=True))).ravel()
return log_ml # (L,)

Data Availability
The processed dataset described in this article will be
deposited upon manuscript acceptance in the Ecological
Frontiers data community hosted by Science Data Bank
(ScienceDB) at https://test.scidb.cn/en/c/ef, per the
journal’s Data Paper submission requirements; the DOI
will be added at that stage. The underlying raw data are
publicly available from the Environmental Data Initiative
repository as data package knb-lter-and.5216, released
under a CC BY 4.0 license.

2.7. Chronological split
Due to the 2019–2020 survey gap, a fixed calendaryear partition boundary (e.g., train ≤ 2018, validation
= 2019, test ≥ 2020) silently produces an empty validation split. We instead split by cumulative event volume
along the continuous τ axis (80/10/10), as detailed in Algorithm 8, ensuring robustness against irregular sampling
gaps. The resulting train, validation, and test partitions
contain 16,085, 2,011, and 2,011 events, respectively, spanning 2011–2017, 2017–2018, and 2018/2021. Splitting midyear at train/validation and validation/test boundaries introduces no data leakage, as the partition strictly respects
elapsed time τ .
